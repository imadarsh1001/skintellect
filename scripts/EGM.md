## Overview
Developer checks and evaluation commands for the skintellect checkout, explicitly excluded from the installed runtime package by the package docstring: "Developer checks and evaluation commands; not runtime dependencies" (`scripts/__init__.py` module docstring). The package holds three offline developer gates (`check.py`, `audit_workspace.py`, `check_query_parser.py`), two evaluation harnesses (`evaluate_review_nlp.py`, `evaluate_release.py`), and one manual smoke driver (`test_copilot_intents.py`). The scripts only orchestrate checks and aggregate reports; all domain logic is delegated to the `skintellect` package under `../src`. The package also serves as an import target: `tests/test_release.py:143` imports `scripts.evaluate_release.evaluate` directly.

This file is a generated EGM contract. The pre-existing, human-maintained quick reference at [./README.md](./README.md) is intentionally not modified by this file.

There are no code-bearing subdirectories (only the generated `__pycache__`, which is out of scope).
